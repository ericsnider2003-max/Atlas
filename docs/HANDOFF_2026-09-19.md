Read in this order:

in a row silently dropped a guard.

## 1. What changed this round

Two sessions of work, 17–19 September. Seven new modules, four bug fixes in
existing ones, twenty guards, and one idea that turned out to explain most of
the defects found.

### The idea: a mechanism standing in for a judgment nobody made

Every real defect found in these two sessions is the same shape. Somewhere,
code was making a decision that looked like a decision but was actually an
accident of implementation:

| where | what it looked like | what it actually was |
|---|---|---|
| `hollow::spoken` | "the worst problems first" | match-arm declaration order |
| `reach::outlier` | "an unusually good post" | `typical * 5.0`, from nowhere |
| `overnight::in_window` | "night" | two integers, 22 and 6 |
| `research::rests_on` | "well grounded" | `sources > 0` |
| `person::is_late` | "a late day" | `peak * 0.5` |
| `Post::quality` | "a quality score" | a hand-fitted `* 20.0` |

None of these were wrong in a way a test would catch, because each one *was*
the specification. The fix is not a better constant. It is to give the system a
place where a judgment is actually made, out of measured data, with the
confidence in it reported — which is what `judgment.rs` is.

### New modules

- **`src/judgment.rs`** — the substrate. Weighted signals into named bands
  (`add_up`, `which_band`, `how_strongly`); a measured value against its own
  history (`Measured`, `how_unusual`, `ordinary_for`, `ordinary_for_counts`);
  several partial measurements weighed together (`weighed_together`,
  `only_partly_measured`); and ranking by severity rather than by order
  (`severity_of`, `worst_first`, `worth_raising`). Shares `whichone::Clarity`,
  so "how sure is it" means one thing across the tree.

  It uses **median and mean absolute deviation**, not mean and standard
  deviation. Standard deviation squares the
  outliers, which is precisely wrong when the outliers are the thing you are
  trying to detect. For counts, `ordinary_for_counts` floors the spread at
  `√middle`, because identical hourly counts give zero spread and then
  everything is infinitely unusual.

- **`src/whichone.rs`** — the choice primitive. `Reading{id, plain, means, not}`
  weighed into `Weighed{clarity, best, behind, margin}`. Gross and net evidence
  are tracked separately so two readings that disclaim each other report
  `Close` rather than `Nothing` — a cancellation to zero is not the same as no
  evidence at all, and reporting it as such sent the caller down the wrong path.

- **`src/nearby.rs`** — LAN discovery over UDP broadcast, port 8789, forty
  lines of `std::net` and no third party. This is the missing half of
  `Path::SameNetwork`: `kin`/`elsewhere`/`server` could always talk to another
  Atlas, but only if you hand-typed an IP that a home router changes on reboot.
  **Discovery is not trust** — an answer carries a name and a port, never a
  token. Answering is off by default; looking is on.

- **`src/telegram.rs`** — the one chat service with a real interface for a
  personal account. `messaging.rs` has had a truthful six-platform table since
  it was written; WhatsApp and Signal can never work without driving a desktop
  app while pretending to be you, which gets accounts banned. Off by default,
  `offline: false` in the catalogue, nothing depends on it.

### Changed

- **`src/daily.rs`** — `Arrival{StillGoing, Starting, BackAgain}` and
  `Whereabouts{Here, Asleep, Out}`. Atlas now tells the difference between you
  working through the night and you starting a day, without being told. The
  brief fires on request *and* on first arrival of the day.
- **`src/overnight.rs`** — `start_hour`, `stop_hour` and `in_window` are
  **deleted**. Overnight work is now gated on `Whereabouts`, not the clock, so
  it runs when you are asleep *or* out for an extended period, and stops when
  you come back rather than at 6am.
- **`src/daemon.rs`** — `last_brief_at`, `last_turn_of_yours`, `worked_while`.
  `turn_from()` sets the turn time from the supplied `t`, not `clock()` —
  the old version was wrong everywhere time is injected, which is everywhere
  it is tested.
- **`src/person.rs`**, **`src/reach.rs`**, **`src/hollow.rs`** — every
  hand-fitted threshold replaced with a `JudgmentConfig` reading.
- **`src/prose.rs`** — real bug: `contraction_rate` was overwritten on every
  `learn()` instead of blended. Now weighted by a new `words_seen` field.
- **`src/research.rs`** — `WELL_READ` bands, `how_well_read()`, `rests_on()`.
  Research now says what its answer rests on instead of counting sources.
- **`src/http.rs`** — `https_get()` via `native_tls`; `read_bounded` made
  generic.
- **`src/capability.rs`** — 27 stale `Planned` entries corrected, `telegram`
  and `mesh` added.
- **`src/main.rs`** — real bug, found by regenerating `METRICS.md`:
  `unwired_from_wiring_test` read `UNWIRED_BASELINE` with `split(',')`. Every
  entry in that baseline is followed by a comment saying why it is there, and
  comments contain commas, so the split chopped the prose into fragments and
  every non-empty fragment became a module name. `docs/METRICS.md` shipped
  saying 18 modules were unreachable and listing `tested (28`, `19`, `13` and
  two paragraphs about `afterme`. The real number is 1. Now reads line by
  line, with `tests/metrics.rs` holding the property — **third time this exact
  parser has been written, second time it has been wrong the same way**; the
  first was `tests/capability_wiring.rs`, where a comment ending in a full stop
  swallowed `"mesh"`.

### Nine name collisions, found and fixed

The deadness scans read **bare function names**. A function with no caller
looks alive if any other module defines the same bare name. Nine of these
surfaced in two days, each one holding a dead function up:

`install::plan_for`→`what_to_fetch` · `Platform::honest`→`what_it_permits` ·
`whichone::weight_of`→`evidence_for` · `telegram::path_for`→`updates_path` ·
`Mesh::from_setting` (not `named`) · `judgment::{total, grade, holds, how_bad}`
→`{add_up, which_band, how_strongly, severity_of}`

`retention::total_mb` was unmasked by the `install::total_mb` rename and is
now wired. **This is a live hazard for the merge**: renaming anything in the
Main Atlas tree can unmask a dead function here, and vice versa.
`tests/name_collisions.rs` is the guard; `NAME_COLLISION_ONLY` currently
carries 130 accepted entries.

## 3. How to work in this tree

Practical constraints that cost hours to rediscover:

- **`cargo build --all-targets` exhausts the disk.** There are 308 test binaries.
  Build and run them in batches of about twelve — `/tmp/claude-0/batch.sh` does
  this and prunes `target/debug/deps` between batches.
- **A two-minute shell timeout is shorter than a full test run.** Background it
  (`setsid nohup … & disown`) and poll a log file.
- **If you clear `target/debug/deps`, also clear `.fingerprint`, `build` and
  `incremental`** — otherwise you get `can't find crate for zerocopy`.
- **The self-reference trap.** A test asserting `!source.contains("X")` fails on
  the comment explaining that X is gone. This bit four times. Strip comment
  lines before the scan, or build the needle at runtime from pieces.
- **Deadness scans read bare names**, so a test that merely *quotes* a function
  name can make the scan count it as tested. See §1.

`/tmp/claude-0/dump_testonly.rs` is a standalone rustc replica of the deadness
scan that dumps the names it finds, so two trees can be diffed without a cargo
rebuild. That is how the `TEST_ONLY_MAX` 380-vs-381 discrepancy was resolved
honestly rather than by moving the number.

## 4. Build plan — what to do next, in order

Ordered by value per unit of effort, with what each one unlocks.

### First, because they unblock other things

1. **Fetch `whisper`.** Five capabilities are `Blocked` on it alone — `wake`,
   `dictate`, `accents`, `translate`, and through them the last module on
   `UNWIRED_BASELINE` (`consent`, which needs a spoken consent flow to have a
   caller). One download unblocks the entire Hearing area.
2. **Fetch `piper`.** `speak` is blocked on it. Atlas currently has no voice out.
3. **Fetch `ffmpeg`.** `endpoint` is blocked on it — audio in.
4. **Decide the `reason` question.** `reason` is `Blocked` on "a language
   model". This is the largest single open architectural decision in the tree
   and it is a *policy* decision, not a technical one: what local model, at what
   size, and what Atlas is permitted to do with its output unsupervised. See §9.

### Then, the substrate's remaining callers

5. **`money` per-bucket baselines.** `judgment::ordinary_for` is built and
   tested and `money` is the obvious caller — "this month's grocery spend is
   unusual for grocery spend" rather than "unusual for spending". It needs
   retained months of data that do not exist yet. The code is ready; the
   history is not.
6. **`handshape` calibration.** It takes twenty calibration samples and
   discards them. `ordinary_for` over those twenty is exactly the right shape
   and would replace a fixed recognition threshold with a measured one.
7. **`voiceid` adaptive threshold.** Same shape, but this is a *security*
   question rather than an ergonomics one: a threshold that adapts to accepted
   samples drifts toward accepting more. Needs a ruling before it is built.

### Then, the long tail

8. **The 238 test-only methods** (§7.3). Each is built, proven and never
   called. They are not bugs; they are capability that exists and is not
   reached. Working through them by module is the single largest source of
   cheap wiring left — `mind` (7), `enrol` (6), `handshape` (6),
   `delegate` (5), `flow` (5).
9. **The 45 orphan methods** (§7.4) — nothing calls them at all, not even a
   test.

**One lesson recorded here because it cost a rewrite:** `bug_sweep.rs` used to
hold `STALE_DOC_CLAIMS: usize = 7`. A count says seven documents are wrong and
names none of them, so the cheapest way to make it pass is to write `8`. It is
now a named list, and the document you are excusing shows up in the diff.

The sharper version of the same lesson is in `dead_capabilities.rs`. It used to
hold a single ceiling summing four groups. One of those groups — *helper, also
tested* — is live, working, tested code. When the brief was rebuilt as ten
small well-named functions, the ceiling went **up** by six, and inlining all
ten into one unreadable function would have brought it down. **A ratchet that
rewards the worse version of the same code is worse than no ratchet, because it
gets obeyed.** That group is now held to nothing, deliberately.

## 8. Documents — what is true and what is not

`docs/` holds 47 markdown files. **Four were true this morning.** The rest
described a tree between a third and a half of this one's size, and there was
no way to tell them apart from the outside.

That is now fixed in two ways.

**Every stale document carries a banner in its first lines** saying what kind of
stale it is, the date it was last true, and where the current answer lives.
Nothing was rewritten and nothing was deleted — several of these files carry
reasoning that is still the best statement of why something is the way it is
(`AUDIT.md` argues for deleting the vault; the vault was built instead, and the
argument is still worth reading). Editing them to match later work would
destroy the thing that makes them worth keeping.

**A new guard, `tests/a_document_says_when_it_stopped_being_true.rs`, holds it.**
It fails if a document is neither on the `CURRENT` list nor carrying the
banner, and — the part that actually matters — it fails if a document *on* the
current list states a tree-size number. That is how the rot started:
`COST.md` is about what Atlas costs to run and had "891 tests" in it;
`RESOURCES.md` is about what a laptop needs and had "195 tests". One sentence
each, and each one turned an evergreen document into a dated one without
anybody deciding to.

## 9. Open decisions — things that need a ruling, not more code

These are not backlog items. Each one is blocked on a judgement only you can
make, and writing code before the ruling would be writing the wrong code.

1. **What language model `reason` gets, and what it may do unsupervised.**
   Eight capabilities in the Thinking area sit behind this. The `llm_model`
   key already ships in `tools.yaml` with nothing reading it. This is the
   largest open item in the tree.

2. **Whether `selfwork` may run its own tests.** `selfwork::run_tests` is
   written, tested, and deliberately orphaned. It is Atlas executing code in a
   sandbox and reading the result — the first real step of the self-improvement
   loop. The guard rails exist (`selfgrant`, `sandbox`, `rehearse`); the
   permission does not.

3. **Whether `voiceid` may adapt its threshold.** A threshold that moves toward
   accepted samples accepts more over time. That is the right behaviour for
   ergonomics and the wrong behaviour for a credential.

4. **Whether DPAPI should wrap the vault's own AEAD as defence in depth.**
   Open since 18 Sep, needs Windows hardware to settle.

5. **Whether there will be a mobile build at all.** Six settings and two
   modules (`android.rs`, `ios.rs`) currently record decisions for a thing that
   does not exist. They are honest about it, but they are also six settings
   that will never be read if the answer is no.
