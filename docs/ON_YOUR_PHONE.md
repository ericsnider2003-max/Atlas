# What Atlas can do on an iPhone or iPad

iOS is a much smaller box than Windows. Some of what Atlas does on the laptop
is simply unavailable — not hard, unavailable — and some of what iOS gives you
free is better than anything worth building.

**Short version: it can hear you, talk back, think, remember, read documents
and cameras, and reach the laptop. It can't watch your screen, touch other
apps, or run all the time.**

---

## Works, properly

| | |
|---|---|
| Hear you and transcribe | whisper on the phone, offline. Smaller model than the laptop |
| Talk back | iOS voices, free, good |
| Talk through AirPods | including with the screen off, once started |
| Remember everything | the whole log lives on the phone |
| Search what you've written | same search as the laptop |
| **Scan a document** | iOS does edge detection, straightening and OCR itself — better than anything I'd write |
| Read text out of a photo | built in, offline, quick |
| Receive anything you share to it | links, PDFs, photos, selected text, from any app |
| Calendar, contacts, reminders | with permission |
| Find the laptop on wifi · cloud · cable · AirDrop to iPad | all four |
| Ask the laptop to do something | queues if it's off rather than failing |
| Notify you when the laptop finishes | including through AirPods |
| Lock screen widget · Action Button | one press into listening |

## Works, with a catch

| | catch |
|---|---|
| Think with a local model | smaller than the laptop's. Fine for conversation and notes; send long reasoning home |
| Keep listening with the screen off | only while a conversation is going — it can't sit waiting all day |
| Background work | short bursts when iOS allows. Enough to sync, not to think hard |
| Compose an email or message | it writes it and hands it to Mail. **You tap send** |
| Read your photos | with permission, and you can grant just the ones you pick |

## Cannot, and never will

| | why |
|---|---|
| **Wake on a word while closed** | iOS won't let an app listen in the background. No app gets around this |
| See your screen or other apps | no app can — this is why window and desktop work stays on the laptop |
| Control other apps | iOS has no automation for it |
| Read other apps' data | each app is sealed off from every other |
| Run continuously | iOS gives short windows and takes them away if you waste them |
| Replace Siri | no app can be the system assistant |
| Hold your credentials | this one is a choice, not iOS — the phone is what you're most likely to lose |

---

## The one difference that actually changes how it feels

On the laptop you say the wake word and it's listening. **On the phone you have
to start it.** Five ways, cheapest first:

1. **The Action Button** — one press. iPhone 15 Pro and up.
2. **"Hey Siri, ask Atlas…"** — hands free; Siri hands it straight over.
3. **Lock screen widget** — one tap, no unlock.
4. **Back tap** — double or triple tap the back, set in Accessibility.
5. **Open the app** — always works.

## Where each device wins

**The phone** — scanning anything, catching a thought the moment you have it,
asking something while walking, hearing that the laptop finished.

**The laptop** — anything needing your files, long reasoning, windows and
browser, being there the second you speak with no button, anything with your
credentials in it.
